## B. Rasm yuklash

- `upload(..., {upsert:true})` `PUT` yuborardi (faqat mavjud obyektni yangilaydi). Endi `POST + x-upsert`.
- Kengaytma fayl nomidan olinardi, hajm/tur tekshirilmasdi, bucket `avav2` cheksiz (har qanday fayl, cheksiz hajm). Endi MIME bo'yicha kengaytma, 5 MB, faqat PNG/JPG/WEBP/GIF (klient + bucket).
- `storage.remove` uchun DELETE policy yo'q edi → o'chirish hech narsa qilmasdi. Policy qo'shildi; klient 0 ta o'chirilganini xato sifatida qaytaradi.
- Savol o'chirishda rasm avval o'chirilardi, keyin qator (qator o'chmasa — buzilgan rasm). Endi avval qator.
- Avatar: eski avatar yangisidan **oldin** o'chirilardi (yuklash yiqilsa avatar yo'qoladi). Endi avval yuklash, keyin tozalash; noyob nom (kesh muammosi yo'q).
- Savol tahrirlanganda eski rasm yetim qolardi → endi tozalanadi.

## C. Foydalanuvchi testi

- Savollar yuklanmasa cheksiz spinner → endi xato ekrani + "Qayta urinish".
- Natija foizi faqat javob berilgan savollardan hisoblanardi (1 ta to'g'ri javob = 100%). Endi jami savollar soniga nisbatan.
- `login_streaks` upsert UPDATE policy talab qilardi (ikkinchi qurilmada xato) → `ignoreDuplicates`.
- SAT testlar: admin faqat bo'sh "qobiq" yarata olardi, savol qo'shish UI yo'q edi, talabaga bo'sh test ko'rinardi. Endi har modulga CSV/JSON import, talabalarga faqat savoli bor testlar ko'rinadi.

## D. Supabase (jonli baza)

- `anon` roli barcha jadvallarda INSERT/UPDATE/DELETE/TRUNCATE huquqiga ega (RLS himoya qilgan, lekin TRUNCATE RLS'ga bo'ysunmaydi) → revoke.
- `sat_questions` (to'g'ri javoblar bilan) login qilmasdan o'qilardi → `authenticated`.
- `set_user_role` ni admin ham chaqira olardi; UI "faqat owner" deydi → owner-only, o'zini pasaytirib bo'lmaydi.
- `practice_tests.subject_id` 6 ta eski qatorda NULL → backfill.
- Indekslar: `questions(subject_id, difficulty, order_index)`, `sat_*`.
- Tekshirildi va **muammo emas**: `profiles` da faqat `display_name, avatar_url, exam_date, lang` UPDATE qilinadi (rolga o'z-o'zini ko'tarish yo'q).
- `schema.sql` jonli bazadan orqada (`topics`, `notifications`, `push_subscriptions` yo'q) — haqiqat manbai sifatida ishlatmang.

## E. Vercel / deploy

- Qo'shildi: xavfsizlik sarlavhalari, `/assets` immutable kesh, `sw.js` no-cache, `api/*` no-store, `api/ai.js` `maxDuration: 60`.
- SPA rewrite endi `/api`, `/assets`, statik fayllarni ushlamaydi (eskirgan chunk HTML sifatida emas, 404 bo'lib qaytadi).
- `sw.js` ikonkasi mavjud bo'lmagan `favicon.ico` ga ishora qilardi.
